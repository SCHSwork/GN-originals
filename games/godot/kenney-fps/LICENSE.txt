Blaster Arena (Kenney FPS)
Source: https://github.com/KenneyNL/Starter-Kit-FPS/tree/185fd2326d74a5cf858cffc616f87cf9696f9cc0

Plays on the Godot Engine 4.6.2 web build shared in games/_godot/4.6.2 (MIT, see the LICENSE.txt there).
Changes: exported for the web with Godot 4.6.2 (single-threaded); the shared engine file is loaded gzipped through a small script added to index.html.
