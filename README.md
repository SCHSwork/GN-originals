# GN Originals

Open-source browser games for [GN 2.0](https://github.com/SCHSwork/math). Every game here is shared under its creator's own license, and all credit goes to them.

GN 2.0 reads `games.json` and shows these games in its **GN Originals** row. They load through jsDelivr, GitHub and githack, like the rest of the site.

## Changes made to the copies

The games are unchanged, except for small fixes so they work inside GN 2.0:

- `http://` links to font and library sites now use `https://`, so browsers don't block them.
- Links that would have sent the whole site to another page (creator logos, credits) now open in a new tab.
- A few file paths that assumed the game was at the root of a website now point to the game's own folder (A Dark Room, Astray, Avabranch, The House).
- Tower Building's "play again" button restarts the game in the player instead of reloading the page.
- Removed third-party scripts that loaded from outside sites: Hextris's remote `a.js`, the Clay.io SDK in Zop and Parity, and the Facebook SDK in Parity.
- Untrusted loads jQuery 1.10.1 (MIT) from its own folder. Its soundtrack is too large to copy (about 160 MB), so the music streams from the original repo.
- Unused files are left out (build tools, packaged downloads, `node_modules`, design files).

## Licenses to keep in mind

Most of these games use MIT, BSD, MPL, GPL or public-domain licenses, which allow sharing as long as the license and credit stay with the game.

Three games are **non-commercial only**:
- Captain Rogers (CC BY-NC 4.0)
- Untrusted (CC BY-NC-SA 3.0)
- Infectors (CC BY-NC-SA 4.0)

They're fine on GN 2.0 because it is free and shows no ads. If the site ever shows ads or charges money, remove these three.

Games under share-alike or GPL licenses (Swap, Starship Sorades, Hextris, Clumsy Bird, and the two above) must stay under those same licenses. Keep their license files with them.

## Adding a game

1. Make sure the game's license allows sharing it. MIT, BSD, Apache, MPL, GPL, CC BY or CC BY-SA all do. Skip games with no license, and clones of commercial games or characters.
2. Copy the game's files into `games/<name>/`, including its license file.
3. Add a square cover image (400×400 PNG) at `covers/<name>.png`.
4. Add an entry to `games.json`. Use the next unused `id`. Ids start at 100001 so they never clash with the main library.

```json
{
  "id": 100034,
  "name": "My Game",
  "author": "Creator name",
  "authorLink": "https://github.com/creator",
  "path": "games/my-game/index.html",
  "cover": "covers/my-game.png",
  "special": ["puzzle"],
  "license": "MIT",
  "licenseFile": "games/my-game/LICENSE",
  "source": "https://github.com/creator/my-game",
  "description": "One sentence about the game."
}
```

GN 2.0 picks up changes on its own. jsDelivr can take up to 12 hours to show them; until then the site may serve the previous version.

To take a game down (for example, if its creator asks), delete its folder and its `games.json` entry.
